Here's how it works:

- It's a hosted REST API, so your Linux server calls it over HTTPS. There's nothing to install, and any language with an HTTP client works (cURL, Python, Node, PHP and so on).
- Endpoints: merge, split, rotate, compress, protect, PDF to Word, Word to PDF, PDF to JPG/PNG and JPG/PNG to PDF.
- Docs and code samples: https://smallpdf.us/developers
- OpenAPI spec: https://smallpdf.us/api/v1/openapi.json

To get started:
1. Create a free account at https://smallpdf.us/auth/signup
2. Generate a key at https://smallpdf.us/account/api
3. Send it in the X-API-Key header, for example:

   curl -X POST https://smallpdf.us/api/v1/compress \
     -H "X-API-Key: YOUR_API_KEY" \
     -F "file=@document.pdf" -o compressed.pdf
