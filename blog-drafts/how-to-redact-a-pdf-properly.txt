To redact a PDF properly, you have to remove the sensitive content from the file, not just cover it up. Drawing a black box or highlight over text in most PDF editors hides it on screen, but the words are often still in the file, and anyone can copy them out. A real redaction tool replaces that part of the page so there's nothing left to recover.

This mistake catches professionals too. In January 2019, a court filing by Paul Manafort's lawyers had blacked-out passages that reporters read simply by copying the text and pasting it elsewhere.

<h2>Why Black Boxes Fail</h2>

A PDF is built in layers. The text sits in one place and anything you draw is added on top. When you put a black rectangle over a name, the name doesn't go away. It's just hidden from view, and the file still contains it.

That leaves several easy ways to get the hidden text back:

- Select the area and copy it, then paste into any text editor
- Search the document with Ctrl+F, which can find words under the box
- Open the file in a PDF editor and move or delete the rectangle
- Run a basic text extraction tool over the file

The same goes for white boxes, highlighter set to black, and black-coloured text. All of them change how the page looks and leave the content in place.

<h2>What Real Redaction Does</h2>

True redaction permanently removes the content underneath. Our <a href="/redact-pdf">Redact PDF</a> tool does this by turning each page you mark into an image and burning the black boxes into its pixels. The text under a box no longer exists as text, so copying, searching and editing have nothing to find.

Pages you don't mark are left as they were. On marked pages, we also add a hidden text layer to what's left, so the rest of the page can still be searched and copied. That text comes from reading the final image, after the boxes are burned in, so redacted words can't come back this way.

<h2>How to Check That It Worked</h2>

Never send a redacted file without testing it. It takes about a minute:

- Press Ctrl+F and search for a name or number you removed
- Try to select the blacked-out area, copy it and paste it somewhere
- Skim every page, since the same detail often appears in headers, footers or signature blocks

If the search finds nothing and the paste comes up empty, the redaction worked. Keep the unredacted original somewhere safe, and make sure you send the redacted copy, not the original with a similar file name.

<h2>What People Forget to Redact</h2>

Missed details are the other common failure. Before you start, look for:

- Account numbers, ID numbers and dates of birth, which often repeat across pages
- Email addresses and phone numbers in signatures and footers
- Names inside charts, table captions and image labels
- Pictures of signatures, stamps and ID cards
- File properties such as title and author, which sit outside the page content

Page redaction works on what's on the page, so check the file name and document properties too. Also remember that context can give things away: if a sentence still says "the CFO of the company", blacking out the name doesn't achieve much.

<h2>Can Redacted Text Be Recovered?</h2>
Not if the redaction was done properly, because the original content is no longer in the file. With our tool, marked areas become solid black pixels. If someone only drew a shape over the text, then yes, it can usually be recovered in seconds.
